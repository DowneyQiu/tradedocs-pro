开单流程（5 步，按顺序走就不会乱）与导出提示
① 客户与报价② 产品与金额③ 条款与收款 ④ 装箱与唛头（可跳过）⑤ 单证与出单
日常只需要 「＋ 新建订单 / 报价」→ 保存 → 单证中心导出 PDF。客户档案、产品库、装箱明细都是可选的提效步骤，用到时再填；订单弹窗右上角可切换「单页显示全部」。
导出前请核对金额、收款账户与装箱数据；打印对话框只需勾选「背景图形」，页眉和页脚（about:blank / 日期 / 页码）已由系统自动抑制。

新建订单 / 报价

① 客户与报价 — 先确定「卖给谁」

两个编号不要填反：订单编号是每单唯一的项目号（客户 PO 抬头、唛头、文件名都用它）；客户采购单号是客户给的 P/O，可能一个 P/O 对应多张订单、多单复用，不必唯一。客户没有给 P/O 就留空。

从客户档案选择公司名会自动带入地址、联系方式与该客户的专属价。此步只填客户与编号，金额下一步填。

② 产品与金额 — 再确定「卖什么、多少钱」

合计：0.00
按贸易术语逐项报价（默认收起；客户要 FOB / DDP / DAP 比价时展开）

本单所有贸易术语、逐项单价、地点、运费责任都只在这里录入一次。一行一个产品、一列一个贸易术语：主术语那一列是基准价，不用填；其他列填该产品在该术语下的单价，留空表示按主价计入。数量一律取上方产品行，整单总价由「数量 × 逐项单价」自动汇总，没有第二个可以填数量的地方。表格下方可补每列的地点、运费责任与备注。
要 FOB 一份、DAP 一份独立报价单，请到「单证中心 → ⑤ 按贸易术语分别出报价单」；本页只是录入界面，一张正式发票 / 合同仍只有一个贸易术语。

参考币种只用于给客户看折算价，不改变应付金额。合计由产品行自动算出，无需手填。

③ 交易条款与收款 — 怎么付款、怎么运、收哪个账户

印度等高风险客户常用 100% 全额预付，也可选 80% / 50% / 30% 或直接改比例。选预设后，下方文字会自动同步，避免「比例 100%、文字却写 50% 定金」这类自相矛盾的单证。按手册 5.2，新客户不做无预付款订单，FFKM 等高价值产品须 100% 或至少 50% 预付。

出单主体：读取中…
固定用于报价、PI、合同、商业发票、装箱单、唛头及报关通关的抬头、地址、签字方；无需选择，也不会随收款账户改变。

收款账户只决定汇款资料里的户名 / 账号 / 银行，不改变任何单证的出单主体；户名与出单主体不同属正常收款安排。

按《AI询盘处理工作手册 v1.2》5.3：仅在客户确认订单、进入正式付款环节后才可提供完整账户；Quotation 一律不显示。

报价方案核对（只读）· 模具费 · 合规说明（默认收起）

下面是第 ② 步「按贸易术语逐项报价」的只读核对，属于本订单自己的数据，每单各自保存，不是每次导出临时生成的。术语、数量、单价、整单总价都来自第 ② 步的产品行，这里不能改，也不会自己变：要改价格或增删术语，请回第 ② 步。客户要 FOB 一份、DAP 一份分别外发时，到「单证中心 → ⑤ 按贸易术语分别出报价单」导出；合并报价单只用 Quotation 显示比价表，PI / 合同 / CI / PL 仍按主术语出单。

填了模具费金额并点「保存订单」后，系统会自动把它作为商品明细表最后一行加入，并计入 Total Amount、大写金额、PI 预付款与合同金额；报价说明下方不会再重复列一次。要改金额或说明请回到这里改，明细表那一行会按本步骤的值自动重建。没有模具费就留空或填 0，单证上不打印任何模具费字样（多术语报价仍会明确答复「No mould / tooling cost」）。合规说明按你填写的原文打印，留空则不显示，系统不会替你编造认证。复制旧订单会清空术语方案、模具费与合规说明，并去掉上一单的模具费明细行，避免把上一单的价格带到新单。

④ 装箱与唛头 — 发货阶段才需要，可以先跳过

包装箱：0

相同箱号表示同一箱。毛重、箱规是整箱数据；同箱填写不同值会标为「待核对」。箱体积每箱只计一次，净重按产品行累加。装箱数量必须与订单数量一致才能对外发送 PL。

本单证允许打印的参考编号

按业务环节分开存放：客户 P/O 属买方信息，L/C 属付款，B/L / 集装箱号属装箱单运输信息。单证只调用自己该显示的编号。

默认勾选 N/M（无唛头），系统不会替客户编造唛头。勾选 N/M 时，装箱行里手填的唛头会统一显示为 N/M，避免自相矛盾。

⑤ 出单 — 选语言、选单证、导出

默认「简洁输出」按你实际归档的单证排版：发票一页英文、装箱单六列、唛头三行；不带条款堆砌、中文大写、印章占位圈与买方签字栏。已保存的旧订单不会自动改变排版。

从同一订单快照生成单证

五种单证共用同一份订单快照与同一套卖方资料，但导出时一份单证就是一个文件：到「单证中心」点对应卡片即可单独预览 / 打印 / 下载，不会连成一个多页 PDF。打印时只需勾选「背景图形」，页眉页脚已自动抑制。
