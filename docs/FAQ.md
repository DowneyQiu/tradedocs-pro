# 常见问题

### 这是开源软件吗？

不是。是**源码可见 · 非商业化分发**（Source-Available）。
代码全部公开、可免费自用和改动，但禁止拿软件本身售卖或做收费服务，
因此不符合 OSI「开源定义」第 6 条。对外请说「源码公开」，别说「开源」。
完整条款见 [LICENSE](../LICENSE)。

### 我公司能用吗？会不会因为公司是营利的就不行？

能用，这正是它被做出来的用途。工厂、贸易公司装在自己设备上，
给自己的客户做 PI、合同、发票、装箱单，都属于许可明确允许的「自用」。
**使用者是不是营利主体，不影响授权**；被禁止的是「拿软件本身当商品或服务卖钱」。

### 我改了代码要公开吗？

不用。只在本单位内部用的修改，没有公开义务。
但如果你把改后的版本发给别人，要免费、保留署名与同样条款。

### 能不能帮客户代做单证收点服务费？

如果是**收费**的代做单证、代出单服务，不行，需书面商业授权。
你自己公司的单证不在此列。

### 能搭成网站 / 内网多人共用吗？

不行。本软件设计为本机单用户离线工具，`LICENSE` 第 3.2 条禁止 SaaS、
托管与多人共用服务端。技术上也没有做多人协同与权限隔离。

### 数据会上传吗？

不会。只监听 `127.0.0.1`，`Cache-Control: no-store`，无远程接口、无遥测。
数据全在 `tradedocs.sqlite3`。

### 为什么打印出来配色不对 / 有 about:blank？

「另存为 PDF」时**勾选「背景图形」**。
页眉页脚由 A4 零页边距样式抑制，若仍出现，检查是否用了浏览器的
「打印简化页面」类扩展。

### 为什么装箱单不让我出？

缺实测重量／体积等装箱数据时会拦截。这是防止把带空值的单证发出去。
请补工厂实测数据或已签发的装箱数据。

### 出厂带真实客户或账户资料吗？

不带。出厂是空库、空白主体与账户模板、中性 Logo。
演示数据是一键载入、带 DEMO 标注的虚构示例。

### 有问题找谁？

到项目仓库提 Issue。本版本不提供付费技术支持，也没有在线客服或授权校验。
